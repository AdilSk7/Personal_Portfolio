Welcome to my personal portfolio repository! This project serves as an interactive, highly dynamic showcase of my software engineering capabilities, built from the ground up to emphasize stunning aesthetics and bleeding-edge user experience. 

It heavily features premium **Glassmorphism UI** elements, fluid micro-animations, and a completely custom **3D Orbital Solar System** navigation mapped entirely via CSS and JavaScript physics. 

## ✨ Key Technical Features

- **3D Solar System Architecture**: A fully engineered physics-based navigation system where technical proficiencies and credentials orbit a central core.
- **Serverless GitHub Integration**: Directly proxies my live GitHub profile stats and latest repositories dynamically using isolated, secure **Vercel Edge API** functions without hardcoding secrets in the browser. 
- **Premium Glassmorphism**: Utilizes highly customized backdrop filtering, radial gradients, and bespoke ambient drop-shadows to craft a premium spatial depth perception.
- **Lightning Edge Deployment**: Built for maximum speed, relying natively on un-bloated DOM painting natively hosted and distributed on Vercel's global CDNs.

## 🧰 Tech Stack
- **Core Architecture:** HTML5, CSS3 (Advanced Animations/Gradients), Vanilla JavaScript (ES6+).
- **Cloud / Backend Edge:** Vercel Serverless API (`/api`).
- **Data Parsing:** Asynchronous external REST API consumption (GitHub data pipeline).
